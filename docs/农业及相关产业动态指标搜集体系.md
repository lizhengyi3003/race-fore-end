# 农业及相关产业分层动态指标搜集体系（东北振兴版）

> 依据《农业及相关产业统计分类（2020）》编制 · 面向**东北振兴区域**涉农信贷风险评估 · 树形分层

## 一、设计说明

**适用范围**：面向**东北振兴区域**（黑龙江、吉林、辽宁及内蒙古东部）内的**涉农小微企业、农民专业合作社和个体工商户**（不含农户个人信贷）。指标按**树形层级**组织（基本项 → 大类 → 中类 → 小类）。

**适用区域**：「适用区域」列标注东北区域内细分范围（"东北全境"或"黑龙江""吉林""辽宁""黑龙江+吉林""黑吉辽+蒙东"等；蒙东五盟市属东北振兴范围，与黑吉辽统一口径）。

**指标命名**：跨类别/跨层级同名指标已加「类别·」前缀，保证全局唯一；中类与其小类不重复设同一指标。

**一票否决**：「是否一票否决」= 是的指标为授信红线，任一命中直接拒贷。

**特色指标**：「是否特色指标」= 是的为**东北/寒地区域特色**指标（黑土地、寒地、人参、冷水鱼、冰雪等），通用经营指标标"否"。

**权重**：1-5 级（★ = 最低，★★★★★ = 最高）；重点核心指标及战略级特色指标（人参、梅花鹿、黑土地、冰雪、冷水鱼、粳稻、亚麻等）已升档。

**采集周期**：年报/季报/月报/实时，用于数据时效管理；静态资质类（许可、认证、合规）按年报采集。

**评分规则**：为自动化评分提供映射依据；占比/能力类正向指标一律"越高得分越高"，风险类指标"越高风险越高"，方向与风险含义一致。

**指标类型**：数值/枚举/布尔/文本；效率类指标取值说明要求**连续3个月生产报表均值**。

## 二、整体依据（联网核实整理）

补贴/认证/保险类指标**均经联网核实确认真实存在**：玉米大豆稻谷生产者补贴、农机购置与应用补贴、黑土地保护性耕作补助、轮作休耕补贴、完全成本/收入保险、农业保险保费补贴、绿色食品/有机/地理标志/GAP 认证等；行业分类依据《农业及相关产业统计分类（2020）》《国民经济行业分类》（GB/T 4754-2017）；信贷与征信指标依据涉农信贷政策、金融监管总局新型农业经营主体信用建档评级要求、替代数据征信实践及行业许可登记制度。补贴金额为动态指标，表格仅提供近年参考区间，**以当年官方公示为准**。
